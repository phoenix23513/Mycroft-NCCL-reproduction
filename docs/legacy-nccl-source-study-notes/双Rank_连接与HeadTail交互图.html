conn.head 和 conn.tail 是指向计数器的指针。GPU 与本地 Proxy 通过各自映射访问对应的共享值。点击任意计数器卡片查看其归属。

GPU 准备写下一片发送数据时，要读发送 head 检查空间；准备读接收数据时，要读接收 tail 检查数据。本例最多用两个 slot，所以发送空间检查都能通过。

演示约定：两台机器、每台一张 GPU、一个 Channel；普通非共享、未注册用户 buffer 的 NET SIMPLE 路径。四元素向量分成两个 chunk，每个 chunk 在图中用一个归一化 step 表示，起点为 0、展示 8 个逻辑 slot。真实 NCCL 的 chunkSteps / sliceSteps、循环次数与计数增量由执行参数决定。本图是可重复的教学推演，选取一种合法交错顺序；它不展示实机时间或插桩结果。发送请求完成和远端 GPU 消费是独立事件。Proxy 写接收 tail 前的 flush 只在连接配置需要时执行。
发送和接收框表示同一个本地 Proxy progress CPU 线程中的两类处理函数。CPU/GPU、communicator 和 buffer 框分别表达执行者、软件对象与存储对象，不代表同一种内存包含关系。
